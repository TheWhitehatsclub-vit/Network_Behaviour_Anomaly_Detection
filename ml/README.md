# ML Module — Network Behaviour Anomaly Detection

This folder contains the machine learning component of the NBAD project. It uses an **Isolation Forest** model to detect anomalous network traffic.

## What this does

The model learns what "normal" network traffic looks like, then flags incoming traffic that deviates from that pattern as a potential anomaly (e.g. a DoS attack, port scan, etc.).

## Status

⚠️ **Currently using fake/sample data.** Real training data from the traffic simulator team has not been integrated yet. Do not treat current model outputs as representative of real-world accuracy.

## Files

| File | Purpose |
|------|---------|
| `train.py` | Trains the Isolation Forest model and saves it to `model.pkl` |
| `predict.py` | Loads `model.pkl` and exposes a `predict()` function for the backend to call |
| `model.pkl` | The saved, trained model (generated by `train.py`, not hand-written) |

## Setup

Install dependencies:
```bash
pip install scikit-learn pandas joblib matplotlib numpy
```

## Usage

**Train the model:**
```bash
python train.py
```
This generates fake normal/attack traffic, trains the model, prints predictions on the fake attack data and a sample of normal data, and saves the result to `model.pkl`.

**Run a prediction:**
```bash
python predict.py
```
This loads the saved model and runs one example prediction.

## The `predict()` function

```python
predict(connection_count, packet_size, data_sent, duration)
```

**Inputs:** 4 numeric features describing a single traffic sample.

**Returns:** a dictionary —
```python
{
    "label": "ANOMALY" or "Normal",
    "score": float  # more negative = more anomalous
}
```

This is the function the backend (FastAPI) should import and call for each new traffic sample.

## Required input columns

When the real traffic CSV is integrated, it must contain (or be mapped to) these columns:
- `connection_count`
- `packet_size`
- `data_sent`
- `duration`
